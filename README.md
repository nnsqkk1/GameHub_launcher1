# GameHub Launcher

Десктопный игровой лаунчер для Windows на C++ с использованием WinAPI.

## Возможности

- Каталог игр с названием, версией и описанием
- Поиск по названию в реальном времени
- Установка игры с прогресс-баром
- Запуск игры через ShellExecuteExW
- Открытие папки игры в проводнике
- Удаление игры (только запись или вместе с файлами)
- Сохранение библиотеки между запусками
- Тёмная и светлая темы оформления
- Статистика по играм
- Контекстное меню по правому клику

## Технологии

- C++17
- WinAPI (Common Controls)
- ShellExecuteExW для запуска процессов
- CMake 3.20+
- Visual Studio 2022

Сторонние библиотеки не используются.

## Сборка

Требования: Windows 10/11, Visual Studio 2022, CMake 3.20+.

Через Visual Studio:
1. Файл → Открыть → Папка, выбрать папку проекта
2. Дождаться генерации CMake
3. В выпадающем списке выбрать GameHubLauncher.exe
4. Нажать F5

Через командную строку:
cmake -B build
cmake --build build --config Release
build/Release/GameHubLauncher.exe

Важно: файл main.cpp сохранять в кодировке UTF-8 with BOM, иначе русский текст будет отображаться неправильно.

## Использование

Установка игры: вкладка «Каталог» → выбрать игру → «Скачать» → дождаться прогресса.

Запуск игры: вкладка «Библиотека» → выбрать игру → «Запустить».

Открыть папку игры: в библиотеке выбрать игру → «Открыть папку».

Удаление: в библиотеке выбрать игру → «Удалить» → выбрать вариант (с файлами или без).

Смена темы: вкладка «Настройки» → «Тёмная тема» или «Светлая тема».

## Пути

Игры устанавливаются в:
C:\Games\GameHub<Название игры>\

Библиотека сохраняется в:
%APPDATA%\GameHubLauncher\library.dat

## Планы нашей команды

- Подключение к GitHub API
- Превью-картинки для игр
- Автообновление лаунчера
- Сворачивание в системный трей
- Выбор папки установки через диалог
- Подсчёт времени в игре в реальном времени

## Примечания

- Перед пересборкой закрывать запущенное приложение, иначе ошибка LNK1168
- Закрыть процесс: taskkill /f /im GameHubLauncher.exe
- Если CMake не собирает — Проект → Удалить кэш и перенастроить
